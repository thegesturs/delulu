Hub / API Routes

API Routes

Expand apps/api on Cloudflare Workers — no new NestJS/Fastify service.

Placement decision

Extend apps/api (Hono on CF Workers). Already has Convex client, OpenAPI, API key auth, rate limiting. Add /internal/* and /webhooks/* route groups.

Internal routes (worker ingress)

Auth: x-api-key: LAMBDA_SECRET_KEY (same as trigger-sqs)

MethodPathPurpose
POST /internal/publish/heartbeat Job → PROCESSING; log attempt STARTED
POST /internal/publish/complete Report attempt result; derive post status

POST /internal/publish/complete — request

{
  "publishJobId": "k57abc...",
  "attemptNumber": 2,
  "sqsMessageId": "abc-123",
  "workerId": "lambda-request-id",
  "durationMs": 45230,
  "result": {
    "success": true,
    "platformPostId": "17841...",
    "platformPostUrl": "https://instagram.com/p/..."
  }
}

// Or on failure:
{
  "publishJobId": "k57abc...",
  "attemptNumber": 2,
  "result": {
    "success": false,
    "errorCode": "RATE_LIMIT_EXCEEDED",
    "errorMessage": "Rate limit exceeded for Instagram",
    "errorClass": "TRANSIENT",
    "retryAfter": 300
  }
}

Response

{ "ok": true, "jobStatus": "PUBLISHED", "postPublishStatus": "PARTIAL" }

Worker change

// packages/worker/client.ts — replace:
await convex.mutation(api.posts.updatePostPublishStatus, { ... });

// with:
await fetch(`${API_URL}/internal/publish/complete`, {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "x-api-key": process.env.LAMBDA_SECRET_KEY,
  },
  body: JSON.stringify({ publishJobId, attemptNumber, result }),
});

app.ts mount

// apps/api/src/app.ts
import internal from "./routes/internal";
import webhooks from "./routes/webhooks";

app.route("/internal", internal);   // no API key middleware — uses x-api-key
app.route("/webhooks", webhooks);   // per-webhook verification
