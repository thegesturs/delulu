PlanetScale decision gate

Revisit PlanetScale migration only if 2 or more triggers become true:

  • Convex cost or document limits block growth
  • Need complex SQL reporting joins across 10+ tables
  • Hiring constraint: team only knows SQL/Prisma
  • Regulatory requirement for self-hosted MySQL
  • Need cross-service ACID transactions with non-Convex services

Reference DDL in 07 Schema exists for that future path. No dual-write planned now.

Dependencies

  • SST deploy access for SQS DLQ config
  • CF Workers deploy for apps/api internal routes
  • Convex deploy for new tables
  • Call Me Later dashboard access (Phase 4 URL update)
