Executive Overview

What we're fixing, what we're keeping, and what we're building.

Problem in one sentence

Publishing success and failure share the same posts.status field and mutation path, so multi-platform posts can be corrupted, retries don't exist, and there is no audit trail per attempt.

Recommendation

Keep Convex. The fragility is architectural, not a database-provider limitation. Add publish_jobs and publish_attempts tables, derive post status from jobs, and stop letting the worker mutate post state directly.

PlanetScale migration is deferred (XL effort, ~2–3 months). Revisit only if Convex cost/limits, SQL reporting needs, or hiring constraints force it.
