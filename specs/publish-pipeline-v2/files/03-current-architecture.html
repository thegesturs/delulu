Missing layer

There is no orchestration layer between SQS and Convex. The worker is both executor and state writer. This is the primary architectural gap v2 addresses.

Real-time updates

The dashboard subscribes to Convex queries (getPosts, getPostById). When a worker patches posts.status, the UI updates in real time. This subscription model is preserved in v2 — only the write path changes.
