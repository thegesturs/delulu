Patterns to adopt from Postiz

  • Isolated execution state — Postiz State enum on each integration-post; we use publish_jobs.status
  • Workflow-level retry — Temporal maximumAttempts: 3, initialInterval: 2min; we use SQS redrive + exponential backoff
  • Missing post recovery — searchForMissingThreeHoursPosts; we add stuck-job sweeper
  • Slim payload to worker — Postiz strips unused fields before activity; we freeze payloadJson at job creation

Do NOT copy

  • Temporal + NestJS orchestrator — operational overhead disproportionate at current scale
  • PostgreSQL/Prisma — no migration benefit for this problem
  • One post row per integration — would break Delulu's unified editorial post UX
  • Postiz AI features — out of scope
