Schema Design

New tables in Convex; reference MySQL DDL for future PlanetScale migration.

Single source of truth (SSOT)

Do not duplicate schema. All publish-pipeline enums and validators live in one module. Mutations, queries, apps/api, and docs reference it — they do not redefine literals.
ArtifactPath
Publish enums + base schemaspackages/database/convex/schemas/publish.ts
Shared post enums (existing)packages/database/convex/schemas/enums.ts
Barrel exportpackages/database/convex/schemas/index.ts
Table + indexespackages/database/convex/schema.ts
TS types (app/API)Infer<typeof …> or PUBLISH_JOB_STATUS from schemas

Each enum: v.union validator + as const object + exported type — same pattern as POST_STATUS in enums.ts.

Convex — publish_jobs (schema.ts registration)

// schema.ts — fields come from basePublishJobSchema; status uses publishJobStatusSchema
publish_jobs: defineTable(basePublishJobSchema.fields)
  .index("by_post_status", ["postId", "status"])
  .index("by_provider_status", ["socialProviderId", "status"])
  .index("by_idempotency", ["idempotencyKey"])
  .index("by_run", ["runId"])
  .index("by_retry", ["status", "nextRetryAt"])

Field definitions (in basePublishJobSchema): postId, socialProviderId, runId, status: publishJobStatusSchema, errorClass: v.optional(errorClassSchema), payloadJson, etc. — all in schemas/publish.ts, not inlined here.

Reference MySQL DDL (PlanetScale — future only)

CREATE TABLE publish_jobs (
  id            VARCHAR(36) PRIMARY KEY,
  post_id       VARCHAR(36) NOT NULL,
  social_provider_id VARCHAR(36) NOT NULL,
  organization_id VARCHAR(64) NULL,
  user_id       VARCHAR(36) NOT NULL,
  run_id        VARCHAR(36) NOT NULL,
  status        ENUM('QUEUED','PROCESSING','PUBLISHED','FAILED','DEAD_LETTER')
                NOT NULL DEFAULT 'QUEUED',
  attempt_count INT NOT NULL DEFAULT 0,
  max_attempts  INT NOT NULL DEFAULT 5,
  next_retry_at TIMESTAMP NULL,
  idempotency_key VARCHAR(128) NOT NULL,
  payload_json  JSON NOT NULL,
  platform_post_id VARCHAR(255) NULL,
  platform_post_url VARCHAR(512) NULL,
  last_error_code VARCHAR(64) NULL,
  last_error_message TEXT NULL,
  error_class   ENUM('TRANSIENT','PERMANENT') NULL,
  queued_at     TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  started_at    TIMESTAMP NULL,
  finished_at   TIMESTAMP NULL,
  created_at    TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at    TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
                ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_idempotency (idempotency_key),
  INDEX idx_post_status (post_id, status),
  INDEX idx_provider_status (social_provider_id, status),
  INDEX idx_retry (status, next_retry_at),
  INDEX idx_run (run_id)
);

CREATE TABLE publish_attempts (
  id              VARCHAR(36) PRIMARY KEY,
  publish_job_id  VARCHAR(36) NOT NULL,
  attempt_number  INT NOT NULL,
  status          ENUM('STARTED','SUCCEEDED','FAILED') NOT NULL,
  error_code      VARCHAR(64) NULL,
  error_message   TEXT NULL,
  error_class     ENUM('TRANSIENT','PERMANENT') NULL,
  provider_response_json JSON NULL,
  duration_ms     INT NULL,
  worker_id       VARCHAR(128) NULL,
  sqs_message_id  VARCHAR(128) NULL,
  created_at      TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_job_attempt (publish_job_id, attempt_number),
  INDEX idx_job (publish_job_id)
);
