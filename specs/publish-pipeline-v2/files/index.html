Publish Pipeline v2

Infrastructure & data-layer spec for fixing Delulu Social's fragile publishing architecture. Keep Convex, add publish job orchestration.

Status: Draft  ·  Last updated: 2026-07-04  ·  Effort: M (~3–4 weeks)

Verdict

Convex remains the system of record. Introduce publish_jobs + publish_attempts tables, derive post publish status from jobs, and route worker writes through apps/api internal endpoints with HMAC auth.

Implementation order

  • Phase 0 — Instrument (3 days)
    PostHog events, spec documentation
  • Phase 1 — Additive schema (1 week)
    publish_jobs, publish_attempts, shadow mode
  • Phase 2 — Dual path (1 week)
    SQS publishJobId, worker → API, DLQ
  • Phase 3 — Cutover (3 days)
    Remove direct worker writes, derive status
  • Phase 4 — Webhooks (1 week)
    apps/api webhook routes
  • Phase 5 — Cleanup (3 days)
    Stuck-job sweeper, FREE plan block
