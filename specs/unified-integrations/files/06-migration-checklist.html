Add a platform (post-migration)

After Phase 5, adding a network (e.g. Reddit) takes at most five steps.

1. Scaffold platform folder

mkdir -p packages/integrations/src/platforms/reddit

Copy platforms/threads/ as baseline:

  • definition.ts — wires sub-modules
  • meta.ts, auth.ts, publish.ts, rules.ts, settings.ts

2. Implement auth and publish

  • auth.ts: getConnectUrl, handleCallback, refreshToken
  • publish.ts: throws IntegrationError on failure, returns PostResult
  • Env vars in packages/api/keys.ts + deployment secrets

3. Register

import { redditIntegration } from "./platforms/reddit/definition";

export const integrationRegistry = {
  // ...existing
  REDDIT: redditIntegration,
};

Add REDDIT to SocialTypes in packages/validators/post.ts if needed.

4. Smoke test

  • Connect via /api/callback/reddit
  • Publish a test post
  • Verify Convex updatePostPublishStatus → PUBLISHED

5. Optional UI

Add preview/settings components only if the platform needs custom UI beyond the generic composer.
