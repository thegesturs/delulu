# Support

Use GitHub Discussions for self-hosting questions, integration help, and design
discussion. Use GitHub Issues for reproducible bugs and scoped feature requests.

Include the Delulu version, deployment mode, relevant service logs with secrets
removed, and the exact command or request that failed.

Hosted customers can use the support channel linked from the product. Billing or
account-specific information should never be posted publicly.

Do not use Discussions or Issues for suspected vulnerabilities. Follow
[SECURITY.md](./SECURITY.md) and report privately.
