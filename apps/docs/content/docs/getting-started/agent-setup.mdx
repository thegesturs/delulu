---
title: Set up Delulu with an AI agent
description: Give an agent the Delulu skill, authorize once, and let it guide setup through publication.
---

You will install one small skill, give your agent one setup prompt, approve delegated access in the browser, and let the agent handle the command-line setup.

For a browser-capable hosted agent, configure the [hosted MCP server](/mcp/overview/) instead. It follows the same setup journey with authorization code and PKCE. Agents can also discover the workflow from `https://solulu.delulu.social/auth.md`.

## Step 1: Install the skill

With Node.js 20 or newer installed, run the Vercel skills command from any
directory:

```bash
npx skills add thegesturs/delulu \
  --skill manage-social-publishing \
  --global \
  --yes
```

The command detects supported AI agents and installs the skill at user scope, so
it is available in any project. You do not need to clone Delulu, install the
Delulu CLI yourself, or configure credentials. The skill contains instructions
only and never copies or stores credentials.

Start a new conversation after installation so your agent discovers the skill.

## Step 2: Use one setup prompt

Ask your agent:

```text
Set up Delulu for me, connect my LinkedIn account, and tell me what remains before I can publish.
```

Replace LinkedIn with the social account you want to connect. The skill teaches
the agent to install the small `delulu` CLI if it is missing, run
`delulu login`, and continue from the live setup state.

Open the verification URL the agent gives you, sign up or sign in, select a
workspace and scopes, and approve. Tokens stay in the CLI credential file with
owner-only permissions and never enter the conversation.

## Step 3: Complete browser ceremonies

The agent may give you separate URLs for:

1. Social-provider consent.
2. Hosted subscription checkout.

These are separate because each provider must receive your explicit consent. The agent polls Delulu after each callback or payment webhook and reports the next action from backend state.

Then ask it to publish:

```text
Upload ./demo.mp4 and publish it to my LinkedIn account with the caption “A better way to understand plans.”
```

The agent should use one atomic `delulu post … --media … --now` command and report the returned state.

## What you built

Your agent can operate the same CLI you can inspect yourself. It can prepare media, create drafts, schedule, publish, retry failed targets, and navigate reviews without receiving raw credentials.

## Troubleshooting

- Start a new agent conversation after installation; already-running sessions may not discover newly installed skills.
- Run `npx skills list --global` to confirm that `manage-social-publishing` is installed.
- Run `npx skills update manage-social-publishing --global` to update the skill.
- Run `delulu --toon` yourself to inspect the exact machine-readable result.
- Use `delulu accounts` when two accounts share a display name; agents should pass canonical selectors.
- Run `npx skills remove manage-social-publishing --global` to remove the skill without logging out of Delulu.
