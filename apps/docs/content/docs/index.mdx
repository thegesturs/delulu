Delulu gives people and agents one permission-aware publishing system across connected social accounts. Start with the CLI for the shortest path from sign-in to a confirmed post, use MCP for hosted agents, or integrate directly with the REST API.

## Fastest start: one skill, one prompt

With Node.js 20 or newer installed, add the Delulu skill globally for your
detected AI agents:

```bash
npx skills add thegesturs/delulu \
  --skill manage-social-publishing \
  --global \
  --yes
```

Then start a new agent conversation and ask:

```text
Set up Delulu for me, connect my LinkedIn account, and tell me what remains before I can publish.
```

The agent installs the small Delulu CLI if needed and guides the rest of setup.
You only handle the browser approvals that require human consent. See the
[agent setup guide](/getting-started/agent-setup/) for details.

## One system, three surfaces

| Surface | Best for | Start here |
| --- | --- | --- |
| **CLI** | Local media, scripts, and agent-friendly TOON output | [CLI overview](/cli/overview/) |
| **MCP** | Hosted agents using structured tools and public media imports | [MCP overview](/mcp/overview/) |
| **REST API** | Direct integrations with typed request and response contracts | [API reference](/api-reference/) |

Every surface returns the actual post state. A command that returns `pending_review`, `publishing`, or `failed` does not claim the post is published.

## Core workflow

```text
authorize → select workspace → connect account → confirm payment
         → upload/import media → draft, schedule, or publish
         → inspect the authoritative result
```

Social-provider consent and checkout remain browser ceremonies. The CLI or agent starts each ceremony, returns the exact URL, and resumes after the callback or webhook succeeds.
