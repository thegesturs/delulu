Delulu gives people and agents one permission-aware publishing system across connected social accounts. Start with the CLI for the shortest path from sign-in to a confirmed post, use MCP for hosted agents, or integrate directly with the REST API.

## One system, three surfaces

- **CLI** for local media, deterministic scripts, and agent-friendly TOON output.
- **MCP** for hosted agents that import public media URLs and call structured tools.
- **REST API** for direct integrations using the same workspace, role, scope, quota, and review rules.

Every surface returns the actual post state. A command that returns `pending_review`, `publishing`, or `failed` does not claim the post is published.

## Core workflow

```text
authorize → select workspace → connect account → confirm payment
         → upload/import media → draft, schedule, or publish
         → inspect the authoritative result
```

Social-provider consent and checkout remain browser ceremonies. The CLI or agent starts each ceremony, returns the exact URL, and resumes after the callback or webhook succeeds.
