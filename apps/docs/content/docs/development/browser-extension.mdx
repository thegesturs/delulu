---
title: Browser extension
description: Build and package the optional browser extension from the monorepo.
---

The optional extension lives in `apps/sorted` and is built with WXT.

```bash
pnpm --filter @delulu/sorted dev
pnpm --filter @delulu/sorted compile
pnpm --filter @delulu/sorted build
pnpm --filter @delulu/sorted zip
```

Firefox equivalents use `dev:firefox`, `build:firefox`, and `zip:firefox`. Generate icon variants with `pnpm --filter @delulu/sorted generate-icons`.

Before submitting a store release, verify permissions, privacy disclosures, authentication, subscription handling, export behavior, generated archives, and screenshots against the current implementation. Write store copy from the current release rather than keeping a long-lived copy document in the repository.
