`@delulu/http-api` serves the contract-derived HTTP interface and OAuth authorization server.

## Public surface

- `GET /health` for liveness and a database probe.
- `GET /v1/instance` for deployment capabilities.
- `GET /openapi.json` and `GET /docs` for the generated contract.
- OAuth discovery, authorization, token, revocation, and JWKS routes.
- Workspace resources under `/v1`, including posts, media, connections, reviews, automations, analytics, billing, members, and API keys.
- Signed webhook routes for social providers, identity, billing, and lifecycle events.

The authentication layer accepts workspace API keys, Delulu OAuth access tokens, and Clerk session JWTs. Authorization always intersects the resolved role with credential scopes.

## Local Cloudflare runtime

```bash
pnpm pg:up
pnpm pg:migrate
pnpm dev:api
```

## Node runtime

The self-hosted API reuses the same typed fetch handler:

```bash
pnpm --filter @delulu/http-api start:node
```

Use `deploy/self-host/.env.example` as the source of truth for self-hosted configuration. Hosted bindings are declared in `apps/api/wrangler.toml`; secret values belong in the deployment platform, never in source control.
